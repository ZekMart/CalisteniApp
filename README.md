# Calistenia Competitiva · versión instalable

Funciona sin conexión, se instala como app y puede leer el pulso del reloj por Bluetooth.

## Publicar en GitHub Pages
1. Creá un repositorio nuevo (por ejemplo `calistenia`) y subí estos 5 archivos a la raíz:
   `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`.
2. En el repositorio: Settings → Pages → Source: "Deploy from a branch" → rama `main`, carpeta `/ (root)`.
3. Abrí `https://<tu-usuario>.github.io/calistenia/` en Chrome del celular.
4. Menú ⋮ → "Instalar app" (o "Agregar a pantalla de inicio").

## Pasar tus datos desde la versión de Claude
1. En la app dentro de Claude: Historial → Sesiones y ajustes → Respaldo → "Copiar datos".
2. En la versión instalada: mismo lugar → pegá en "Pegar datos para importar" → "Importar".
Para volver a llevar datos a Claude, hacé lo mismo al revés.

## Pulso del Huawei Watch GT 6 Pro
1. En el reloj: Ajustes → Transmisión de datos de frecuencia cardíaca (HR Data Broadcasts) → aceptar → iniciar un entrenamiento.
2. En la app instalada: Historial → Sesiones y ajustes → Reloj o pulsómetro → "Conectar por Bluetooth" y elegí el reloj.
3. Cargá tu edad para las zonas de pulso y, si querés, activá el "Descanso inteligente".
Si tu reloj no muestra esa opción, funciona igual con cualquier banda de pulso Bluetooth.

## Diferencias con la versión de Claude
- Los datos quedan en el celular (no se sincronizan con tu cuenta de Claude).
- El análisis con IA y la opinión de Claude no están disponibles.
- Todo lo demás es igual, y además funciona sin internet.
